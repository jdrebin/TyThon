Current boundary

  
    
    
  • Stdlib and third-party libraries still need .d.ty contracts. The pandas sketch in the markdown README is an illustration, not bundled support.
    • 
    
  • Verified packages are Linux x64 / WSL. Do not pip install tython. The distribution name is tython-lang.
    • 
    
  • Erasure is not validation. readonly and ! do not become runtime checks.
    • 
    
  • Formatting still rejects some syntax. Navigation is partial.
    • 
  

  
Install, emit, and the full prose live in the markdown README. The checker test TestReadmeExamples reads that file, not this page.
