# tython support

This project is independent of Microsoft. Do not send tython-specific issues to
the TypeScript repository or Microsoft support channels.

Report ordinary bugs at [jdrebin/TyThon](https://github.com/jdrebin/TyThon/issues).
For a useful report, collect the build identifier, a minimal `.ty` / `.d.ty` example, expected
and actual behavior, and relevant editor output. Remove credentials and private
data. Known limitations are listed in the extension README.
